# Taskify ✅

> A modern, full-stack Todo web application built with the MERN stack, featuring secure user authentication and a sleek Glassmorphism UI.

**Live Demo:** [Click here to view the live app!](https://mytaskify-nu-orcin.vercel.app)

## 🌟 Features

*   **Secure Authentication:** User registration and login powered by JSON Web Tokens (JWT) and securely encrypted passwords.
*   **Complete CRUD Operations:** Users can create, read, update, and delete their own personalized tasks.
*   **Real-time State Management:** Instant UI updates when adding, editing, or toggling completed tasks.
*   **Modern Glassmorphism UI:** A beautiful, elegant, and responsive frosted-glass interface built with pure CSS.
*   **Protected Routes:** Only authenticated users can access and manage their personal task lists.

## 💻 Tech Stack

**Frontend:**
*   React.js
*   Vite
*   Axios
*   React Router DOM
*   Pure CSS (Glassmorphism design)
*   Deployed on **Vercel**

**Backend:**
*   Node.js
*   Express.js
*   JSON Web Tokens (JWT) for Authentication
*   Bcrypt.js for Password Hashing
*   Deployed on **Render**

**Database:**
*   MongoDB
*   Mongoose ODM
